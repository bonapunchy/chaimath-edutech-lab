## 다음 주차 과제 만들기 (빈 틀 사용법)

`template/` 폴더에 바로 쓸 수 있는 빈 틀이 있습니다. 두 단계짜리 활동, 실험 노트, 텍스트 저장이 이미 작동합니다.

1. **폴더 복사**: `template` 폴더를 통째로 복사해 이름을 `week7`처럼 바꿉니다.
2. **✏️ 표시 고치기**: `lab.html`과 `lab.js`에서 `✏️ [바꿀 곳 1~6]` 표시가 있는 곳만 고치면 됩니다.
   - 1·2: 탭 제목, 주차 번호, 과제 제목
   - 3: 각 단계의 설명·문제 (단계를 늘리려면 `<section class="panel step">` 하나를 복사하고 번호를 바꿈)
   - 4: 학원관리프로그램 아이디어
   - 5: `lab.js`의 단계 이름 목록 (lab.html의 단계 수와 같게)
   - 6: `lab.js`의 저장 이름 (`'week7-note'`처럼 주차마다 다르게)
3. **첫 화면에 추가**: `index.html`에서 `<section class="hub-week">` 하나를 복사해 주차 번호·제목·링크를 바꿉니다.
4. **이 README 목록에 한 줄 추가**: 위 목록에 `- 7주차 ○○ : week7/lab.html`을 적습니다.
5. **공개 전 확인** (아래 체크리스트)
